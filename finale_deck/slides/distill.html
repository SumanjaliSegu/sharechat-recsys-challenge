IDEA 2 · TRAINING-ONLY DISTILLATION

Use request context to train, never to predict

Teacher

LightGBM that also sees request size and position. Out-of-fold AUC 0.886. Trained on training rows only; it never scores a test row.

Students

PLR networks on row-only inputs, trained on α·label + (1−α)·teacher. Same inputs as every other model at test time.

Host, on the forum: “the model which predicts on the test dataset must not use features derived from request_id/request grouping.”

This is how we used the strongest signal in the data while staying inside the rule. Students became our best single networks at 0.8402. The gain in the blend was small, because the blend was already saturated.
